InsecureBank - synthetic deliberately vulnerable Android fixture
----------------------------------------------------------------
Generated by samples/make_samples.py. This tree exists only as a stationary
scanner benchmark representative of the canonical OWASP Mobile weak spots
described by the OWASP Mobile Application Security Testing Guide. Nothing
here executes; the endpoints are .example placeholders.

Layout:
  app/src/main/AndroidManifest.xml   manifest (debuggable, cleartext, exports)
  app/src/main/java/...              source files carrying weak patterns
  app/build/intermediates/classes.dex  compiled DEX with weak-crypto strings
  assets/ config.properties          build assets
  res/xml/network_security_config.xml cleartext + user-CAS trust anchors
  lib/&lt;abi&gt;/lib*.so                  minimal native images (PIE + non-PIE)
  build/outputs/InsecureBank.apk     compiled bundle (unsigned by design)
